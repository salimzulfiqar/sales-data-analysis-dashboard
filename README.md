# Sales Data Analysis Project

I analyzed sales data to find business insights. This project shows my data cleaning and analysis skills.

## What I Did
1. Cleaned messy sales data
2. Found which regions sell the most
3. Created charts and graphs
4. Found shipping delays

## Tools Used
- Python
- Pandas (for data cleaning)
- Matplotlib (for charts)

## How to Run
1. Open the Jupyter notebook
2. Run all cells
3. See the results

## My Findings
- West region has highest sales
- Furniture products are most profitable
- Shipping takes too long sometimes
